RECAST

Modularizing Real-World Repositories into Composable Training Environments for Coding Agents

Turns existing code repositories into reusable training assets. Each repository is decomposed into dependency-aware modules and recombined into controllable start and goal states, so one codebase yields many verifiable tasks instead of a single issue/patch pair. Deletion-only synthesis keeps real source code as the ground truth; sandboxed execution, replayable provenance and mutation probes harden rewards against weak tests and reward hacking.

把现有代码仓库变成可复用的训练资产。仓库被递归分解为具备依赖关系感知的功能模块，再重组为可控的起点与目标状态，于是一个代码库能生成大量可验证任务，而不只是一组 issue/patch。仅删除式合成保留真实源代码作为标准答案；沙箱执行、可重放溯源和变异探针让 RL 奖励更能抵抗弱测试与奖励投机。

ToolBranch

Efficient Adaptive Tool Use for LLM/VLM Agents

On-policy RL that teaches LLM/VLM agents when to answer directly and when to reach for a tool. Scaffolded Branch-GRPO generates paired tool and no-tool branches for every sample, so both choices keep a comparative reward signal and training avoids the exploration collapse of vanilla GRPO.

一种 on-policy 强化学习方法，让 LLM/VLM 智能体学会何时直接作答、何时调用工具。Scaffolded Branch-GRPO 为每个样本生成成对的“调用工具”与“不调用工具”分支，两种选择都保有可比较的奖励信号，避免原始 GRPO 的探索坍塌。
